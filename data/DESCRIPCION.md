# Descripción del conjunto de datos

Archivo preparado a partir de `processed.cleveland.data` incluido en el material original entregado para Heart Disease.

- Cada fila corresponde a un registro clínico.
- `target = 0`: ausencia de enfermedad según la codificación preparada para este ejercicio.
- `target = 1`: presencia de enfermedad (se agruparon las categorías originales 1–4).
- El archivo contiene algunos valores faltantes en `ca` y `thal`; se dejaron intencionalmente para el laboratorio.

Columnas: age, sex, cp, trestbps, chol, fbs, restecg, thalach, exang, oldpeak, slope, ca, thal, target.

## Nota sobre esta versión académica
El archivo `datos.csv` fue ajustado únicamente en cantidad de registros para mantener una carga de trabajo comparable entre las variantes de la tarea. Las variables, la variable objetivo y el alcance indicado en `README.md` se mantienen sin cambios.
